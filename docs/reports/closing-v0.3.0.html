What Was Built

Domain

  • EvidenceStatus enum with three variants: Drafted, Accepted, Superseded
  • Evidence.status field (last position) + props["status"] JSON injection at construction
  • Provenance-based defaults: UserWorkspace → Accepted, ToolOutput → Drafted
  • from_props with legacy-read default (missing key → Accepted)

Port (GraphStore trait)

  • accept_evidence(&mut self, id, &dyn Clock) — flips Drafted→Accepted, creates Evaluation node
  • supersede_evidence(&mut self, id) — flips Accepted→Superseded (no eval, manual replacement)
  • list_evidence_by_status(&self, path, status) — filter by status, includes legacy rows as Accepted

CLI

  • archctl evidence accept --id <id>
  • archctl evidence supersede --old-id <id>
  • archctl evidence list --status <drafted|accepted|superseded>
