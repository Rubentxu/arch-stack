# Observability & Dogfooding

## Local metrics
Files changed/skipped, hash/parse/extract/write/search times, graph revision, delta size, renderer/layout time, retrieval candidate counts y agent budget/outcome. No external telemetry por defecto.

## Dogfood
Arch Stack debe analizarse a sí mismo: detectar stale docs, dependency violations, Semantic Review de PRs, ADR→code→tests y UAT impact.
