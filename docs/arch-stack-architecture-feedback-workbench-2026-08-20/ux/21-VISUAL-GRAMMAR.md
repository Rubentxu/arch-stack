# Visual Grammar

| Canal | Significado estable |
|---|---|
| shape | entity type |
| border/pattern | epistemic state |
| size | active magnitude |
| fill/value | selected overlay |
| opacity | focus vs context |
| position | topology/hierarchy |
| line pattern | relation status/type |
| glyph | explicit finding/state |

Estados: confirmed, intended, observed, runtime-only, inferred, proposed, conflicting, stale, unverified. No depender sólo del color.

Progressive disclosure: signal → explanation → evidence → source/raw.
