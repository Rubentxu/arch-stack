# Workbench IA & Navigation

```text
Topbar: project / revision / compare / search
Left:   Explore | Analyze | Change | Validate | Stories
Center: active visual workspace
Right:  Moldable Inspector
Bottom: investigation/evidence/events/findings
```

Explore: Architecture, Code, Runtime, Intent, History.
Analyze: Dependencies, Impact, Cycles, Hotspots, Drift, Coverage.
Change: Working changes, Semantic Review, Compare, What-if.
Validate: Policies, Evidence, Tests, UAT, Intent parity.

Inspector contextual: Container puede mostrar Overview/Dependencies/Impact/Runtime/Evidence/History/Decisions/Tests/UAT/Security; Relation muestra Why/Evidence/Runtime/History/Policies.

`⌘K` busca entities, files, ADRs, findings, actions y saved investigations.
