# Accessibility & Performance

## Accessibility
Keyboard core workflows, visible focus, semantic DOM, matrix accessible summary, no color-only meaning, reduced motion, textual alternative for canvas selection y shortcut help.

## Performance
Culling/LOD, adjacency indexes, list virtualization, sparse DSM, visible matrix tiles, workers for ELK/heavy calculations, no relayout for style-only delta, stable positions.

## Budgets
Benchmarks deben ser portables, reproducibles y ligados a hardware/dataset baseline; nunca rutas absolutas de la máquina de desarrollo.
