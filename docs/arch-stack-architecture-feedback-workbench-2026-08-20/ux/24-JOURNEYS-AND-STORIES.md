# UX Journeys

1. Zero→first insight: scan → System Overview → boundaries/hotspot → source.
2. Why: relation → Why → evidence path → source → return.
3. Dense dependencies: graph noise → DSM → matrix cell → graph/source sync.
4. Change impact: changed entity → blast radius → tests/UAT.
5. Intent conflict: Reconciliation Matrix → conflicting cell → evidence per plane.
6. Agent candidate: proposed style → evidence → accept/reject/correct.
7. Architecture Story: explain checkout → guided steps → branch → resume.
8. Semantic Review: intent/architecture/scope/policy/test/UAT delta.
9. Causality: finding → Task → AgentTurn → mutation → revision → feedback.
10. What-if: fork projection → move/split → recompute → compare → ADR/plan.
