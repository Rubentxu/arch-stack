# Visual Thinking Patterns

- **System Map** — dónde está lo importante.
- **DSM** — acoplamiento, capas, ciclos.
- **Evidence Path** — por qué.
- **Concept/Intent Map** — decisiones/rationale.
- **Reconciliation Matrix** — paridad entre planos.
- **Timeline/Causality** — cómo llegamos aquí.
- **Architecture Story** — explicación progresiva.
- **Semantic Review** — significado del cambio.
- **Thinking Canvas** — qué pasaría si; proposal space.

## Design Thinking translation
Discover → Explore evidence; Define → Frame problem; Develop → Proposed architecture; Deliver → Validate policies/tests/UAT; feedback permite iterar.
