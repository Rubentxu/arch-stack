# CUA / Agent Evaluation

## Reglas
- criterios atómicos;
- un estado/screenshot por criterio;
- ground truth determinista cuando sea posible;
- medir agreement antes de dar autoridad;
- token budget suficiente.

## Roles
Scenarist puede proponer rubrics; Playwright actúa determinísticamente; multimodal reviewer es advisory; humano valida comprensión/usabilidad.

No marcar una feature visual como exitosa sólo por PASS de LLM judge.
