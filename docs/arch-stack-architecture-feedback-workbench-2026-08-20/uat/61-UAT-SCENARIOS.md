# UAT Scenarios

## UAT-01 First Insight
Repo desconocido. Identificar áreas principales, hotspot y dependencia relevante.

## UAT-02 Why
Explicar una dependencia y llegar a evidence/source.

## UAT-03 Dense Coupling
Encontrar ciclo conocido. A/B graph vs DSM.

## UAT-04 Incremental Edit
Editar dependencia; verificar delta y equivalencia con full index.

## UAT-05 Intent vs Reality
Encontrar contradicción conocida entre intent/static/runtime.

## UAT-06 False Agent Claim
Agente propone afirmación falsa; nunca llega a fact; rechazo persiste y se reutiliza.

## UAT-07 Agent Causality
Responder qué petición/acción provocó cambio/finding.

## UAT-08 Retrieval
Pregunta requiere ADR + code. Medir recall y `included_because`.

## UAT-09 Semantic Review
Entender significado de un cambio, scope inesperado y tests/UAT afectados.

## UAT-10 Context Preservation
Graph → DSM → Source → Graph sin perder entidad/contexto.

## UAT-11 Scale
1k/10k/50k: selección, zoom, inspector y matrix.

## UAT-12 Accessibility
Resolver tareas esenciales por teclado.

## UAT-13 Architecture Story
Aprender flujo desconocido con story y responder preguntas.

## UAT-14 Feedback Reuse
Corregir candidate; una sesión/agente posterior recibe feedback pertinente.
